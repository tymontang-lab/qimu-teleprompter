# QIMU Teleprompter

一个为 iPhone 竖屏口播设计的极简 PWA。文稿、摄像头、麦克风和录像只在当前设备中处理，不需要账号或服务器。

## V1 功能

- 前置摄像头 + 麦克风录像，支持前后摄像头切换
- 9:16 竖屏优先，1080P / 720P、30fps 优先并自动降级
- 提词自动滚动、连续速度调节、字号调节
- 提词区域上下拖动、70%–90% 宽度调节
- 点击字幕或按钮暂停 / 继续，手指滑动可手动找句子
- 3 秒倒计时、录像计时、录像预览、重录
- iOS 分享菜单优先，另提供视频文件下载
- 镜像预览，录制镜像可选（默认使用更稳定的非镜像录制）
- 本地保存最近文稿与设置
- Manifest、Service Worker、iPhone 主屏幕图标
- 提词和控制界面不会进入最终视频

## 本地运行

要求 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

然后打开终端中显示的本地地址。

摄像头和麦克风只允许在安全环境中调用。`localhost` 可直接测试；若要用同一局域网中的 iPhone 访问电脑地址，需要为本地站点配置 HTTPS。最简单、最可靠的真机测试方式是先部署到 HTTPS 地址。

## 构建与部署

```bash
npm run build
```

项目适合部署到支持 HTTPS 的静态或边缘托管平台。部署后请确认：

1. `manifest.json` 和 `service-worker.js` 可从站点根路径访问。
2. 服务器以 `video/mp4` / `video/webm` 正常返回生成的视频 Blob（视频并不会上传）。
3. 页面没有被嵌入跨域 iframe；iOS 应直接打开顶层页面。
4. 站点必须使用 HTTPS，否则手机浏览器不会开放摄像头和麦克风。

## 部署到 GitHub Pages

项目已经包含可直接使用的 GitHub Actions 工作流：

1. 将项目推送到 GitHub 仓库。
2. 在仓库 **Settings → Pages** 中把 Source 设为 **GitHub Actions**。
3. 把代码推送到 `main` 分支；`.github/workflows/deploy-pages.yml` 会自动安装依赖、执行 `npm run build:pages` 并发布 `dist-pages`。
4. 等待仓库的 **Actions** 页面显示部署完成，再打开 Pages 地址。

如需在本机检查 GitHub Pages 产物：

```bash
npm run build:pages
npx vite preview --outDir dist-pages
```

静态构建使用相对资源路径，仓库部署在 `/仓库名/` 子路径时 Manifest、Service Worker 和图标仍会保持在同一作用域。

## iPhone 添加到主屏幕

1. 用 Safari 打开已部署的 HTTPS 地址。
2. 点击 Safari 底部的“分享”按钮。
3. 选择“添加到主屏幕”。
4. 名称保留为 **QIMU**，点击“添加”。
5. 以后从主屏幕打开即可获得接近全屏 App 的体验。

## 摄像头与麦克风权限

- 首次进入提词模式时，Safari 会分别请求摄像头与麦克风权限，请都选择“允许”。
- 如果误点拒绝：在 Safari 地址栏左侧的页面菜单中打开“网站设置”，把“摄像头”和“麦克风”改为“允许”，然后刷新。
- 也可以前往 iPhone **设置 → Safari → 摄像头 / 麦克风** 检查权限。
- 其他正在使用摄像头的 App 可能导致连接失败，关闭后再试。

## 已知的 iOS Safari 限制

- 网页不能像原生 App 一样无提示直接写入系统相册。QIMU 会优先调用 iOS 分享菜单；在菜单中选择“存储视频”或“存储到文件”。
- Safari 支持的录像容器和编码格式取决于 iOS 版本。应用优先使用 MP4/H.264/AAC，不可用时自动回退到浏览器报告支持的格式。
- “录制镜像”需要通过 Canvas 重新绘制视频，会增加耗电和发热；旧设备或旧版 Safari 可能不支持。默认关闭时直接录制摄像头原始媒体流，稳定性最好。
- 浏览器退到后台、锁屏、来电或切换 App 可能中断摄像头或录像。录制期间请保持页面在前台。
- PWA 的缓存用于应用外壳和设置，不会缓存或上传录制的视频。刷新或关闭预览页后，尚未保存的视频 Blob 可能丢失。
- 不同 iPhone 摄像头实际提供的分辨率不同，1080P 是优先约束而不是强制值；无法满足时浏览器会自动选择最接近的清晰度。

## 隐私

本项目没有账号、分析、广告、云同步或上传接口。文稿与偏好保存在 `localStorage`；录像只存在浏览器内存生成的本地 Blob 中，直到用户分享、下载、刷新或关闭页面。

## 真机验收建议

使用最新版 iOS Safari，粘贴约 1000 字中文稿，完整走一遍：进入提词模式 → 授权 → 调字号和速度 → 拖动提词位置 → 倒计时录像 → 暂停 / 恢复提词 → 停止 → 预览 → 分享保存。最后检查成片中没有字幕或控制按钮，并确认声音正常。
